Start here for pattern-based DSA prep: sliding window, two pointers, intervals, linked lists, trees, heaps, subsets, binary search, and topological sort.
Based on the [dsa-patterns](https://github.com/isayanpal/dsa-patterns) repository, expanded with reusable templates, worked dry runs, extra problem variants, and common bugs.
Every pattern has runnable JavaScript and Java code, and every snippet was executed against test cases.
The original repository also has Python versions.
When you want problems to practice on, the [LeetCode 30-Day Plan](/docs/dsa/leetcode-30-day-plan) lists 150 problems grouped by pattern, with direct LeetCode links.
